# syslog-appliance

Rocky Linux based syslog appliance for virtual and physical deployment.

## Goal

This project aims to build a syslog appliance that can receive, store, search, and manage syslog messages.

## Initial Target

- Rocky Linux 9
- rsyslog
- Python FastAPI
- PostgreSQL
- systemd
- firewalld

## Development Phase

Current phase: initial design and MVP development.
